# Support

Ways to get help with ClippyOS:

1. **In-app docs** — the deployed app ships a docs page at `/docs`.
2. **README + AGENTS.md** — architecture, commands, and contracts:
   [README.md](README.md), [AGENTS.md](AGENTS.md).
3. **Bug reports** — open a GitHub issue using the bug template.
4. **Feature ideas** — open a GitHub issue using the feature template.

Please do not use public issues for security vulnerabilities — see
[SECURITY.md](SECURITY.md).

Response expectations: maintainers triage issues on a best-effort basis;
security reports follow the targets in [SECURITY.md](SECURITY.md).
